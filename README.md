# HKMP.Timer

Синхронизированный таймер для мультиплеера Hollow Knight через HKMP.

## Возможности

* Общий таймер, синхронизированный между игроками.
* Запуск, остановка и изменение времени через команды.
* Автоматическая остановка на `00:00`.
* Отображение состояния таймера.
* 8 цветовых вариантов.
* Настраиваемая клавиша таймера.
* Настройка положения и размера таймера.
* Все пользовательские настройки сохраняются между запусками игры.

## Управление

### Показать / скрыть таймер

Коротко нажмите клавишу таймера.

По умолчанию:

`F8`

### Режим редактирования

Удерживайте клавишу таймера.

В режиме редактирования можно:

* перемещать таймер;
* изменять его размер за границы или углы.

После отпускания клавиши изменения сохраняются.

## Команды

`/timer start` — запускает таймер с установленной продолжительностью.

`/timer stop` — останавливает таймер.

`/timer time <секунды>` — устанавливает продолжительность таймера в секундах.

`/timer status` — показывает текущее состояние таймера.

Вместо `/timer` можно использовать алиас `/tm`.

## Отображение времени

Таймер отображает оставшееся время в формате `MM:SS`.

Например:

```text
05:32
```

Если время вышло, отображается сообщение:

```text
ВРЕМЯ ВЫШЛО
```

После этого таймер автоматически останавливается.

## Настройки

В меню мода доступны:

* **Клавиша таймера** — изменение клавиши управления.
* **Цвет таймера** — выбор одного из 8 цветов.
* **Положение таймера** — изменяется в режиме редактирования.
* **Размер таймера** — изменяется в режиме редактирования.

Настройки сохраняются автоматически.
